# Meta integration review

This app uses Facebook Login and Graph API Page access tokens, not Instagram Login. Meta's [Instagram Platform overview](https://developers.facebook.com/docs/instagram-platform/overview/) says that this configuration requires a Facebook Page linked to an Instagram professional account, appropriate Page tasks and the `instagram_basic` / `instagram_content_publish` permissions. Meta's [Pages API guidance](https://developers.facebook.com/docs/pages-api/getting-started/) describes a Page access token, content-creation task, and Page permissions. The server requests `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic` and `instagram_content_publish`; it checks the grant response at connection and rejects publication for channels whose required grants are absent. This snapshot is not a real-time permission check: Meta remains authoritative at each publishing request and can revoke access, reject a Page task, or require app review. A successful connection does not guarantee future publication.

For Instagram, the server creates a container using a temporary public JPEG URL, waits for processing, then requests publication. That URL must be reachable by Meta. Only a Meta-confirmed ID enters the publication history. Failures after an attempted publication are marked uncertain, not automatically retried. Manually marking an uncertain job reviewed records a user's check, not a server-verified publication.

**Live-account status:** no authorised live Meta test account or deployment credentials were used in this correction. Immediate and scheduled Graph flows have only been tested with mocked responses. Actual permissions, Page tasks, Instagram URL reachability, app review, token expiry and live publication remain unverified.
